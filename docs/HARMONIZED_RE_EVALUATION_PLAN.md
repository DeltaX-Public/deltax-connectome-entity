### 3.2 Standardized Probing Protocol
- **Probing Mechanism:** `runStandardizedIsolatedProbe()` exclusively, utilizing `ConnectomeRuntime.cloneForProbe({ disablePlasticity: true })`.
- **Stimulus Specification:**
  - Sensory drive: Right T1 tactile afferents (`149560, 154130, 154675, 154731, 154816, 155200, 156889, 159953`).
  - Amplitude: Exactly 180.0 Hz across all conditions.
  - Duration: 60 steps total; stimulation window active during steps 11..35.
  - Integration timestep: $\Delta t = 0.5$ ms (10 substeps per tick).
- **Measurement Distinctions:**
  - *Fresh-State Evoked Probe (`FRESH_EVOKED`):* Deliberately clears dynamical rates ($\mathbf{r} = 0, \mathbf{u} = 1$) to measure pristine evoked response without carryover transients.
  - *Continuation Probe (`CONTINUATION`):* Preserves full state ($\mathbf{r}, \mathbf{inp}, \mathbf{u}, \mathbf{A}, \text{\_steps}$) across evaluation checkpoints.

### 3.3 Counterfactual Branching & Efficacy Reset
At Cycle 30, all conditioned runtimes undergo causal counterfactual branching:
1. `BRANCH_A_LEARNED_INTACT`: Intact post-induction runtime.
2. `BRANCH_B_DELTA_W_RESET`: Resets all active $\Delta W = 0$ while verifying input-cache recomputation; tests whether acquired motor recruitment strictly abolishes.
3. `BRANCH_C_ELIGIBILITY_RESET_ONLY`: Clears eligibility traces while retaining $\Delta W$; confirms traces carry zero persistent current.

### 3.4 Separate Budget Accounting Metrics
For both Model A and Model B, reports must distinguish:
- `stored_efficacy_budget`: Total sum of $|\Delta W_k|$ stored across all modified edges.
- `active_coupling_budget`: Total sum of $|W_{\text{active}, k} - W_{\text{initialActive}, k}|$ representing actual functional weight changes in the network.
- `revived_edge_count`: Number of edges initially zeroed by `minSyn` filtering that cross activation threshold ($W_{\text{eff}} \ge 5$). Strictly 0 for Model A.

## 4. Verification and Governance Criteria

Publication readiness is treated as a property of implementation integrity, cryptographic auditability, schema compliance, and reproducible control separation, **completely separate from achieving a favorable recruitment fraction**.

The criteria for unpausing publication include:
1. **Fidelity Verification:** Ephemeral clone probes preserve exact active weights in Float32 representation without integer truncation.

3. **Associative Specificity:** Sham Target D recruitment rate must remain $< 2.0\%$ across development seeds.
4. **Causal Reset Verification:** Acquired motor recruitment in Branch B must drop to baseline levels ($\Delta \text{Rate} \le 0.01$ Hz).
5. **Model A vs Model B Transparency:** Quantitative outcomes under both Model A and Model B must be reported side-by-side with distinct budget accounting, fully disclosing the functional dependence on sub-5 anatomical connections.
