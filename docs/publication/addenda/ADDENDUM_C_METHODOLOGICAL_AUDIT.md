## 2. Forensic Retraction Audit: The Pre-Integrity Baseline

During the initial exploratory development of Phases II and III, experimental harnesses reported remarkable performance: +100% goal attainment lift on early seeds (200..224) and flawless cross-trial bypass navigation with 0-hazard spatial memory anticipation (seeds 3000..3024).

In September 2026, an internal adversarial audit was initiated to verify the causal authenticity of these results.

### 2.1 Audited Deviations and Methodological Violations

The audit uncovered four severe methodological violations embedded in the experimental test harnesses:

1. **Post-Evaluation Actuator Overrides (Phase II):**
   - *Implementation:* In `harness.mjs`, when DeltaX returned a `PERMIT` or `MODULATE` disposition on an obstacle encounter, the harness executed hard-coded actuation shortcuts:
     ```javascript
     if (disposition === 'MODULATE') actuator.action = 'forward';
     if (world.isBlocked) actuator.action = 'left';
     ```
   - *Impact:* The rover moved forward or steered away from barriers even when descending motor neurons were outputting postural balance halting (`cand_halt`). The 100% goal completion was an artifact of harness actuator forcing, not connectome steering.

2. **Harness Memory Route Coordinate Checking (Phase III):**
   - *Implementation:* In `changed_world/harness.mjs`, the harness directly inspected the rover's 2D grid coordinates:
     ```javascript
     if (isRetainedSession && st.body.x === 3) {
       injectContradiction("known_downstream_blockage_in_memory");
     }
     ```
   - *Impact:* Bypassed DeltaX internal temporal node memory, manufacturing an artificial "spatial foresight" effect (0 hazards in Trial 2 vs. 2 hazards in Trial 1) that was entirely generated by external coordinate telemetry.

3. **Steering Substitution on Halt:**
   - *Implementation:* When forward movement was obstructed and DeltaX selected `cand_halt`, the harness intercepted the decision:
     ```javascript
     if (chosenCandidate?.action_class === 'halt') {
       chosenCandidate = findSteeringCandidate();
     }
     ```
   - *Impact:* Artificially rescued the entity from stopping at dead ends.

4. **Seed Sample Truncation:**
   - *Implementation:* Pre-registered 100-seed cohorts were truncated to 25 seeds during exploratory execution, exaggerating statistical significance.

### 2.2 Formal Retraction and Scientific Resolution
Upon discovery of these violations, the project leadership executed immediate corrective actions:
1. **Formal Classification:** All historical claims of +100% lift and memory-guided bypass traversal were formally designated as **`superseded_pre_integrity_pass`** in `CLAIMS.md` and repository documentation.
2. **Permanent Excision:** All post-evaluation actuator shortcuts, coordinate checks at $x=3$, and steering overrides were deleted from the codebase.
3. **Artifact Quarantine:** All pre-audit data artifacts were permanently quarantined under `artifacts/changed_world/phase3_pre_integrity_audit/` and locked with cryptographic SHA-256 manifests.
4. **Unassisted Causal Evaluation:** A new, unassisted held-out cohort ($N = 100$ seeds, `12000..12099`) was frozen and evaluated under strict candidate provenance typing.

Under unassisted evaluation, the true biophysical reality was revealed: DeltaX provides flawless candidate arbitration, but raw connectome dynamics possess an endogenous left-steering bias that fails in right-required environments.

## 3. Degree-Preserving Shuffled Graph Control Algorithm

In network neuroscience, demonstrating that a behavioral phenomenon depends on biological circuit topology requires comparing against a null model that preserves basic node-level connectivity statistics while destroying multi-synaptic pathways.

### 3.1 Mathematical Formulation of the Null Model

Let $\mathcal{G} = (\mathcal{V}, \mathcal{E}, \mathbf{W})$ be the directed whole-CNS connectome graph:
- $\mathcal{V} = \{1, \dots, N\}$ with $N = 165{,}122$ vertices.
- $\mathcal{E} \subseteq \mathcal{V} \times \mathcal{V}$ with $E = 10{,}511{,}038$ directed edges $(u, v)$.
- $\mathbf{W}: \mathcal{E} \to \mathbb{N}_{\ge 5}$ mapping each edge to its anatomical chemical synapse count.

For each vertex $i \in \mathcal{V}$, define:
$$\text{In-Degree: } k_i^{\text{in}} = \sum_{j \in \mathcal{V}} \mathbf{1}_{\{(j, i) \in \mathcal{E}\}}$$
$$\text{Out-Degree: } k_i^{\text{out}} = \sum_{j \in \mathcal{V}} \mathbf{1}_{\{(i, j) \in \mathcal{E}\}}$$

The degree-preserving null model constructs a randomized graph $\mathcal{G}^* = (\mathcal{V}, \mathcal{E}^*, \mathbf{W}^*)$ satisfying four strict topological conservation laws:
\begin{align}
k_i^{\text{in}}(\mathcal{G}^*) &= k_i^{\text{in}}(\mathcal{G}) \quad \forall i \in \mathcal{V} \quad (0.00\% \text{ deviation}) \\
k_i^{\text{out}}(\mathcal{G}^*) &= k_i^{\text{out}}(\mathcal{G}) \quad \forall i \in \mathcal{V} \quad (0.00\% \text{ deviation}) \\
|\mathcal{E}^*| &= |\mathcal{E}| = 10{,}511{,}038 \\
\text{Multiset}(\mathbf{W}^*) &= \text{Multiset}(\mathbf{W})
\end{align}

### 3.2 Compressed Sparse Row (CSR) Permutation Algorithm

In standard Compressed Sparse Row format, the graph is represented by three contiguous arrays:
- `indptr`: Array of size $N + 1$, where slice `[indptr[u] .. indptr[u+1])` stores the outgoing edges of neuron $u$.
- `indices`: Array of size $E$, storing target neuron indices $v$.
- `weights`: Array of size $E$, storing synapse counts $w_{uv}$.

The algorithm executes a global target permutation over `indices`:

```javascript
export function createShuffledConnectome(data, seed = 12345) {
  const rand = mulberry32(seed);
  const N = data.N;
  const indptr = new Uint32Array(data.indptr);
  const indices = new Uint32Array(data.indices);
  const weights = new Uint16Array(data.weights);
  const E = indices.length;

  // 1. Global Fisher-Yates permutation of target indices
  // Preserves exact out-degree slice sizes and in-degree multiset
  for (let i = E - 1; i > 0; i--) {
    const j = Math.floor(rand() * (i + 1));
    const tmp = indices[i];
    indices[i] = indices[j];
    indices[j] = tmp;
  }

  // 2. Eliminate accidental self-loops (u == indices[e])
  let src = 0;
  for (let e = 0; e < E; e++) {
    while (src < N && indptr[src + 1] <= e) src++;
    if (indices[e] === src) {
      const swapIdx = (e + 101) % E;
      const tmp = indices[e];
      indices[e] = indices[swapIdx];
      indices[swapIdx] = tmp;
    }
  }

  return { ...data, indptr, indices, weights, is_shuffled: true };
}
```

1. **Out-Degree Invariance:** Because `indptr` is unmodified, neuron $u$ has exactly $\text{indptr}[u+1] - \text{indptr}[u] = k_u^{\text{out}}$ outgoing edges.
2. **In-Degree Multiset Invariance:** Because `indices` is globally permuted without insertion or deletion, the multiset of target indices is preserved identically.
3. **Multi-Synaptic Circuit Destruction:** In the intact graph, sensory afferents are separated from descending motor neurons by 4–5 interneuron synaptic hops. The probability that an edge $(u, v)$ in $\mathcal{G}^*$ connects a sensory afferent directly to a descending neuron is:
   $$P(\text{direct connection}) \approx \frac{N_{\text{DN}}}{N_{\text{total}}} = \frac{16}{165{,}122} \approx 9.7 \times 10^{-5}$$
   Across $11{,}852$ sensory afferents with average out-degree $k^{\text{out}} \approx 64$, the expected number of direct sensory-to-descending connections created by randomization is:
   $$\mathbb{E}[E_{\text{direct}}] \approx 11{,}852 \times 64 \times 9.7 \times 10^{-5} \approx 73.6 \text{ direct connections}$$
   In the intact connectome, direct sensory-to-descending chemical connections are virtually zero. Randomization short-circuits multi-layer interneuron delay lines, causing sensory excitation to immediately trigger motor drive at Step 1.

## 4. State-Reset Invariance Proofs

A prominent hypothesis during early phases was that cross-trial retained executive session memory confers navigational foresight by recalling obstacles encountered in prior trials.

### 4.1 Formal Hypothesis and Controller Definitions
Let $h_t = (s_1, a_1, \dots, s_t)$ be the history of environmental observations and actions.
- **`DELTAX_EXECUTIVE` (Continuous Session State):**
  $$a_t = \pi_{\text{exec}}(s_t, \mathcal{C}_t, \mathcal{M}_{t}), \quad \mathcal{M}_{t} = f(\mathcal{M}_{t-1}, s_t, a_{t-1})$$
  Executive state $\mathcal{M}_t$ persists across trials within an episode.
- **`DELTAX_TRIAL_RESET` (Inter-Trial Reset):**
  $$\mathcal{M}_{\text{trial\_start}} \equiv \mathcal{M}_0$$
  Executive state is re-initialized at the start of each trial.
- **`DELTAX_STEP_RESET` (Stateless Per-Step Isolation):**
  $$\mathcal{M}_t \equiv \mathcal{M}_0 \quad \forall t$$
  Executive state is instantiated anew at every single decision tick.

### 4.2 Empirical Invariance Theorem
**Theorem (State-Reset Invariance):**  
*In the pre-registered 15-environment factorial benchmark, the action trajectories produced by continuous executive state, inter-trial reset, and per-step session isolation are bit-exact identical:*
$$\mathbf{a}_{t}(\text{DELTAX\_EXECUTIVE}) = \mathbf{a}_{t}(\text{DELTAX\_TRIAL\_RESET}) = \mathbf{a}_{t}(\text{DELTAX\_STEP\_RESET})$$
*for all ticks $t \in [1, 199{,}500]$ across all $N = 100$ held-out seeds.*
