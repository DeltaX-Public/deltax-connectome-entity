## 3. Detailed Chronology of Code Changes After First Held-Out Run

1. **Abbreviation of Seed Count (Seeds 3000..3024):**
   - *Timing:* During initial test script development.
   - *Rationale:* To minimize local evaluation time during exploratory testing, the seed loop was terminated at 25 seeds.
   - *Impact:* Resulted in premature claims based on a 25-seed subsample rather than the preregistered 100 seeds.

2. **Insertion of Harness-Side Diversion at x=3:**
   - *Timing:* Added during memory test calibration.
   - *Rationale:* The connectome substrate without spatial planning failed to enter bypass corridors autonomously. Heuristic logic was introduced into `harness.mjs` to trigger diversion at `x=3`.
   - *Impact:* Produced a spurious "memory anticipation" effect (0 hazards vs 2 hazards) that was entirely manufactured by harness logic rather than DeltaX temporal node memory.

3. **Harness Steering Substitution on Halt:**
   - *Timing:* Added during changed-world recovery debugging.
   - *Rationale:* When forward locomotion was blocked, DeltaX selected `halt`. To make the entity solve the maze, the harness intervened and picked a turning candidate.
   - *Impact:* Inflated EXECUTIVE goal completion to 100%. Raw unassisted executive selection results in safe halting (preventing repetitive wall collisions) rather than autonomous maze traversal.
