# Limitations and non-claims

This repository is intentionally more honest than polished.

- The CI fallback is an `alwaysDecides` stub. It is deterministic scaffolding, not proprietary DeltaX, not a trained executive, and never evidence of DeltaX reasoning.
- No proprietary DeltaX implementation, weights, service, or credentials are included. Canonical API mode only calls a reachable local endpoint.
- The Entity Observatory is a modest field inspector and JSON exporter. It is not a full connectome visualization, neural microscope, or live topology viewer.
- The UI displays recorded fields only. It does not fabricate neural animations, confidence, causality, or telemetry when a checkpoint is absent.
- Numerical replay is bounded by serialized checkpoints, floating point behavior, runtime versions, and the fidelity of recorded packets. Bitwise identity across machines is not promised.
- Broken World is a scaffold for headless causal intervention, checkpoint, and restore workflows. It does not establish full learning, general intelligence, embodiment, or biological equivalence.
- Causal intervention artifacts demonstrate harness accounting and authority ordering. They do not prove that a substrate learned the intervention or that the world model is complete.
- The upstream fly tree is preserved for validation, but its large data files can be slow to clone, inspect, or reproduce.
- Static serving is required for `entity.html`; opening it as a local file can prevent artifact loading.
- An absent API is an explicit failure in DELTAX mode. Choosing the stub is a conscious CI/offline action, not an automatic fallback.
- Export is a snapshot of observable ledger fields, not a lossless dump of a connectome or a substitute for experiment artifacts.
- Biological Multi-Synaptic Latency: An intact 165k-neuron connectome naturally requires multiple simulation steps for sensory propagation through interneuron layers to descending motor neurons. In short 12-step task horizons, this biological latency limits total distance traveled before time expires.
- Control Dynamics: The degree-preserving shuffled connectome control bypasses biological multi-layer interneuron delay lines by wiring sensory afferents directly to motor neurons, highlighting the distinct topological structure of the intact circuit.
- Causal Integrity: All post-DeltaX actuator shortcuts and harness steering substitutions have been permanently removed. The governor can only evaluate and admit genuine pre-evaluation substrate candidates. If DeltaX selects `halt` upon obstacle detection, the entity halts.
- Phase III Spatial Foresight Boundary: Under strict unassisted evaluation (zero harness-side coordinate checks at $x=3$), retained DeltaX session memory does not produce anticipatory steering into bypass corridors or hazard reduction (paired difference: 0.0 ± 0.0). DeltaX coherence governance provides collision safety via halting, but does not provide autonomous 2D grid pathfinding.
- Connectome Autonomy Boundary: The intact connectome alone does not possess long-horizon spatial planning; under sudden environmental blockage, both unguided connectome dynamics and unassisted closed-loop governance stop at the blockage rather than navigating through alternate corridors.
